🔬 Core Methodological Principles & Key Findings

1. Three-Layer Dataset Architecture

Layer 1 (Raw): Preserves every single execution trace (33 total, including 12 failures) with exit codes and raw standard error strings.

Layer 2 (Aggregated): Drops warm-up run 1; computes mean, std, median, and CV%. Enforces strict gating gates.

Layer 3 (ML Ready): Features calculated pre-execution. Gated workloads with incomplete timing validation are strictly blocked.

2. Gating Decision: BFS vs CFD

BFS (Gated / Blocked): OpenMP total path includes graph read while CUDA timers exclude file I/O. Definitional mismatch invalidates speedup. Marked pending_validation.

CFD (Validated): Both OpenMP and CUDA timers measure pure compute across 2000 RK iterations. GPU speedup is 4.71×. Admitted to Layer 3.

3. Strict Anti-Leakage Guarantee

The ML classifier must decide placement before running the workload. The following runtime telemetry values are forbidden as inputs:

  • Measured CPU or GPU execution times
  • Measured H2D or D2H PCIe transfer times
  • Empirical speedup or performance ratios
  • Target label (preferred_device)
4. Model A vs Model B Ablation Study

Model A (Full Features): Uses domain + workload type identity + physical features (13 total).

Model B (Ablated): Removes identity (workload_type & workload_domain). Forces prediction solely from intrinsic physical traits (parallelism, memory boundness, compute intensity, transfer size).

🎓 Key Talking Points for Project Reviews / Viva

1. Why didn't you just train on BFS too?
"Because scientific rigor matters more than raw sample count. OpenMP BFS included file reading in its timer, while CUDA BFS only timed the kernel loop. Training on inconsistent timers would be training on noise. We gated BFS as 'pending validation' and evaluated CFD whose timers are apples-to-apples."
2. Why do you have Model A and Model B?
"Model A proves the classifier works when workload identity is known. Model B proves the model generalizes to completely unknown workloads by relying exclusively on intrinsic computational features like memory boundness, arithmetic intensity, and transfer size, without memorizing benchmark names."
